# DF-3: Create Speaker and Session Objects with Lookup Relationship

## Overview
This branch introduces two new custom objects — `Speaker__c` and `Session__c` — with a lookup relationship from `Session__c` to `Speaker__c`. These objects are part of the conference/event management data model.

---

## Metadata Changes

### 1. Speaker__c (Custom Object)
**File:** `force-app/main/default/objects/Speaker__c/Speaker__c.object-meta.xml`

Represents a speaker participating in a session.

| Field API Name | Type | Description |
|---|---|---|
| `Name__c` | Text (255) | Full name of the speaker |
| `Company__c` | Text (255) | Company or organization the speaker represents |
| `Bio__c` | Long Text Area | Speaker biography / description |

**Layout:** `Speaker__c-Speaker Layout` — includes `Name__c`, `Company__c`, `Bio__c`

---

### 2. Session__c (Custom Object)
**File:** `force-app/main/default/objects/Session__c/Session__c.object-meta.xml`

Represents a session or talk within an event.

| Field API Name | Type | Description |
|---|---|---|
| `Title__c` | Text (255) | Title of the session |
| `Speaker__c` | Lookup (Speaker__c) | Lookup relationship to the Speaker__c object |
| `Room__c` | Text (255) | Room or venue where the session takes place |
| `Start_Time__c` | DateTime | Scheduled start date and time of the session |
| `Capacity__c` | Number | Maximum number of attendees for the session |

**Layout:** `Session__c-Session Layout` — includes `Title__c`, `Speaker__c`, `Room__c`, `Start_Time__c`, `Capacity__c`

---

## Relationships

```
Speaker__c
    └── Session__c.Speaker__c (Lookup)
```

A single `Speaker__c` record can be associated with multiple `Session__c` records via the lookup field `Session__c.Speaker__c`.
